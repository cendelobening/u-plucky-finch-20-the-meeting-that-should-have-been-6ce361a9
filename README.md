One joke about a meeting that should have been an email:

> The meeting peaked when the boss read the email aloud and twelve people nodded like it was breaking news.

## Why it wins

It never complains that the meeting "could have been an email" — it shows the meeting *being* the email: the boss reading it aloud is the high point, and a whole room nodding along as if it were breaking news is a scene everyone who has sat through one recognises instantly. The turn lands on the last two words, and every word earns its place.

## Run it

```sh
python3 main.py
```

Writes exactly one line of plain text (no trailing newline) to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` if set, else `/output`), mode 0644. Pure Python standard library — no dependencies.
